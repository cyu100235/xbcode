# 字典功能与枚举安装同步 — 实施计划

## Summary

补全 `plugin/xbAdmin/config/menu.php` 第 581-634 行已声明但**悬空**的「字典管理」功能：

1. 新增字典数据表 `xb_dict`（单表扁平结构，每行 = 一个字典项，用 `plugin + group` 归类）。
2. 新增后台字典模型、验证器、控制器（`index / add / edit / del`），对齐菜单已声明的 `admin/Dict/*` 权限地址。
3. 新增框架层 gateway HTTP 客户端 `plugin/xbCode/api/Dict.php`（沿用 `api/Menu.php`、`api/Setting.php` 模式）。
4. 在 `DictController` 增加 `report()` 接收接口，供插件安装时上报字典。
5. 在框架层 `BasePlugin` 实现 `installEnum()`：扫描 `plugin/{插件}/enum/*.php`，反射枚举类与常量，整理成字典项，经 gateway 上报后台；并把该步骤移动到 `afterInstall` 之后（与配置、菜单同步并列），避免登录顺序问题。

用户明确的「系统字典」保护：enum 派生记录标记 `is_system=20`，后台**允许改标签文字（label/style/sort），`value` 冻结只读、禁止修改**。

## Proposed Changes

### 1. `plugin/xbAdmin/install.sql` — 追加字典表 DDL

**What**：在文件末尾追加 `xb_dict` 建表语句（含 `DROP TABLE IF EXISTS`，与现有风格一致）。

**Why**：字典功能需要持久化表；安装时由 `BasePlugin::installSql()` 自动导入。

**How**：

```sql
-- 删除表语句
DROP TABLE IF EXISTS `xb_dict`;
-- 表结构：`xb_dict`
CREATE TABLE `xb_dict` (
  `id` int unsigned NOT NULL AUTO_INCREMENT COMMENT '序号',
  `plugin` varchar(50) NOT NULL DEFAULT '' COMMENT '插件标识',
  `group` varchar(50) NOT NULL DEFAULT '' COMMENT '字典分组，即枚举类名',
  `title` varchar(50) NOT NULL DEFAULT '' COMMENT '分组标题，取自枚举类注释',
  `key` varchar(50) NOT NULL DEFAULT '' COMMENT '字典键，即枚举常量名',
  `label` varchar(50) NOT NULL DEFAULT '' COMMENT '显示文字',
  `value` varchar(50) NOT NULL DEFAULT '' COMMENT '字典值，系统字典冻结只读',
  `style` varchar(255) NOT NULL DEFAULT '' COMMENT '样式文本，取自枚举 style',
  `is_system` enum('10','20') NOT NULL DEFAULT '10' COMMENT '是否系统字典：10否，20是',
  `sort` int NOT NULL DEFAULT '0' COMMENT '排序',
  `create_at` datetime DEFAULT NULL COMMENT '创建时间',
  `update_at` datetime DEFAULT NULL COMMENT '更新时间',
  PRIMARY KEY (`id`) USING BTREE,
  KEY `idx_plugin_group` (`plugin`,`group`) USING BTREE,
  KEY `idx_plugin_group_key` (`plugin`,`group`,`key`) USING BTREE
) ENGINE=InnoDB AUTO_INCREMENT=1 DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci ROW_FORMAT=DYNAMIC COMMENT='字典管理';
```

> 说明：不建唯一键。手工新增的字典项 `key` 可为空，唯一约束会互相冲突；幂等性在模型层按 `plugin + group + key` 查找保证。

### 2. 新增 `plugin/xbAdmin/app/model/Dict.php`

**What**：字典模型，`extends plugin\xbCode\app\Model`。

**Why**：承载字典读写与「上报幂等 upsert」逻辑，供控制器与 `report()` 复用。

**How**：

- `register(string $plugin, array $groups): int` — 接收上报，返回写入条数。
  - 入参 `groups` 每项：`['group' => 枚举类名, 'title' => 标题, 'items' => [['key','label','value','style'], ...]]`。
  - 校验 `group` 匹配 `/^[\w\-]+$/`、`items` 非空，非法抛 `ExceptionBusiness`。
  - 逐项：按 `plugin + group + key` 查找（`key` 非空时）：
    - 命中 → 更新 `title/label/style/sort/is_system`，**不改 `value`**（冻结）。
    - 未命中 → 新建，写入全部字段（`is_system = YesEnum::YES`）。
  - 上报项 `sort` 取数组下标（保证枚举声明顺序稳定）。
- `plugins(): array`、`groups(): array` — 返回去重后的 `[['label'=>..,'value'=>..], ...]`，供列表筛选下拉使用。`groups` 的 label 取该组 `title`（取首条），value 取 `group`。

### 3. 新增 `plugin/xbAdmin/app/validate/DictValidate.php`

**What**：字典验证器，`extends Webman\Validation\Validator`，仿 [AdminRuleValidate.php](file:///d:/dev/project/xbcode/plugin/xbAdmin/app/validate/AdminRuleValidate.php)。

**Why**：`add/edit` 提交需要统一校验。

**How**：

- rules：`plugin => required|max:50`、`group => required|max:50`、`title => required|max:50`、`key => max:50`、`label => required|max:50`、`value => required|max:50`、`sort => integer`。
- scenes：`add`、`edit` 均包含上述字段。
- messages：中文错误提示。

### 4. 新增 `plugin/xbAdmin/app/admin/controller/DictController.php`

**What**：字典管理控制器，`extends BaseController`，含 `index/add/edit/del/report`。

**Why**：补齐菜单声明的接口，并提供 gateway 上报入口。

**How**：

- `index(Request $request)`
  - `$request->get('_act')` 时构建 `XbCrud`：筛选 `plugin(select)`、`group(select)`、`label(input)`、`is_system(select, YesEnum)`；列 `group / title / key / label / value / style(HtmlColumn) / is_system(MapColumn, YesEnum::dict('label')) / sort(InputColumn)`；右上操作「修改」(dialog → `edit`) 与「删除」(confirm → `del`)，系统项删除按钮 `->disabledTip('系统字典，禁止删除')->disabledOn('this.is_system == 20')`。
  - 否则按筛选条件查询 `Dict`，`order('sort asc,id asc')` 返回 `successData`。
- `add(Request $request)`
  - `POST`：`xbValidate(DictValidate::class, $post, 'add')` → 强制 `is_system = YesEnum::NO`（手工项非系统）→ `new Dict` 保存 → `success('添加成功', ['id' => ...])`。
  - `GET`：返回 `formView()`，`setSaveMethod('POST')`。
- `edit(Request $request)`
  - `GET`：`findModel(id)` → `setData($model->toArray())` → 返回 `formView()`，`setSaveMethod('PUT')`。
  - `PUT`：`findModel` → `xbValidate(..., 'edit')` → 整理数据 → 若 `is_system = YES` 则 `unset($post['value'])`（冻结，忽略提交值；`plugin/group/key` 也一并 `unset`，避免改变字典身份）→ 保存 → `success('修改成功')`。
- `del(Request $request)`：`findModel` → 系统字典抛 `ExceptionBusiness('系统字典，禁止删除')` → `delete()` → `success('删除成功')`。
- `report(Request $request)`（仿 [ConfigController::report()](file:///d:/dev/project/xbcode/plugin/xbAdmin/app/admin/controller/ConfigController.php#L51-L64)）：校验 `plugin` 正则 + `groups` 非空 → `Dict::register($plugin, $groups)` → `success('上报成功', ['count' => $count])`。
- `formView(): XbForm`：`addRowInput('plugin')`、`addRowInput('group')`、`addRowInput('title')`、`addRowInput('key')`、`addRowInput('label')`、`addRowInput('value')->required(true)->disabledOn('this.is_system == 20')->description('系统字典值由枚举冻结，禁止修改')`、`addRowInput('style')`、`addRowInput('sort')`，并 `addRowHidden('is_system')` 以便 `disabledOn` 表达式取值。
- `findModel(int $id): Dict`：不存在抛 `ExceptionBusiness`。

### 5. 新增 `plugin/xbCode/api/Dict.php`（gateway 客户端）

**What**：字典上报 HTTP 客户端，完全沿用 [Menu.php](file:///d:/dev/project/xbcode/plugin/xbCode/api/Menu.php)/[Setting.php](file:///d:/dev/project/xbcode/plugin/xbCode/api/Setting.php) 的静态客户端模式。

**Why**：后台可能独立部署，插件安装时不直接写 `xb_dict`，统一走 HTTP 上报。

**How**：

- 对外 API：`Dict::install(array $groups, string $plugin = ''): void` → 过滤合法分组后 `self::request('POST', '/xbAdmin/admin/Dict/report', ['json' => ['plugin' => $plugin, 'groups' => $groups]])`。
- 私有/受保护方法 `request()/token()/login()/gateway()/client()` 与 `Setting` 保持一致（`Accept: application/json`、`status === 0` 校验、`timeout 10`、`http_errors false`、缺 guzzle 报错）。

### 6. 修改 `plugin/xbCode/base/BasePlugin.php`

**What**：实现 `installEnum()` 并调整调用位置。

**Why**：原 `installEnum()` 为空且位于 `doInstall`（早于 `afterInstall`），此时超管账号尚未创建，gateway 登录必失败。

**How**：

- `doInstall()`：删除 `self::installEnum($version, $context);` 那一行（保留 `installCrontab` 不动）。
- `install()`：在 `self::installMenu(...)` 之后追加 `self::installEnum($version, $context);`（注释说明依赖 `afterInstall` 创建的账号）。
- 实现 `installEnum(string $version, array|null &$context = null)`：
  1. 取 `$context['name']`，为空抛异常。
  2. `$dir = str_replace('\\','/', base_path("plugin/{$name}/enum"))`；非目录直接 return。
  3. `glob($dir.'/*.php')` 逐个：类名 `plugin\{name}\enum\{basename}`；`class_exists` 且 `is_subclass_of($class, BaseEnum::class)` 才处理（否则跳过）。
  4. `$class::toArray()` → 映射为 `['key','label','value','style']` 项；为空跳过。
  5. 组装 `['group' => basename, 'title' => 枚举标题, 'items' => 项]`。
  6. 汇总非空则 `Dict::install($groups, $name)`。
- 新增私有 `enumTitle(string $class): string`：反射 `getDocComment()`，跳过空行与 `@` 开头行，返回首个描述行；无则回退类短名。
- 文件头 `use` 增加 `plugin\xbCode\api\Dict` 与 `plugin\xbCode\base\BaseEnum`（同命名空间 `base` 下 `BaseEnum` 可直接用，无需 use）。

> 卸载 `uninstallEnum()` 仍留空（用户未要求，保持最小改动）。

## Assumptions & Decisions

1. **数据模型**：单表 `xb_dict`，每行一个字典项，`plugin + group` 归类（用户已确认）。
2. **实现层**：框架通用层 `xbCode`（`BasePlugin::installEnum` + `api/Dict.php`），任意插件只要存在 `enum/` 目录即可被扫描上报（用户已确认）。
3. **系统字典保护**：enum 派生记录 `is_system=20`；后台可改 `label/style/sort/title`；`value` 冻结只读，`edit` 时服务端 `unset` 提交的 `value`（用户已确认）。
4. **系统字典禁止删除**：派生项删除会破坏枚举一致性，故 `del` 拒绝 `is_system=20`（与「系统菜单，禁止删除」一致）。若希望允许删除，请在审阅时指出。
5. **`group` 标识 = 枚举类名**（如 `StateEnum`），`title` = 类 doc 注释首行（如 `启用状态枚举`）。
6. **幂等键**：`plugin + group + key`（`key` = 枚举常量名）。手工新增项不走 upsert，直接插入，`key` 可留空。
7. **不新增前端代码**：全部由后端 amis schema（`XbCrud`/`XbForm`）驱动，沿用现有 SPA 渲染。
8. **路由与权限**：webman 默认路由，URL 为 `/xbAdmin/admin/Dict/{action}`；`report` 依赖超管放行，无需写入 `menu.php`。
9. 不建唯一索引（因手工项 `key` 可为空）；`install.sql` 沿用 `utf8mb4` 与现有表风格。
